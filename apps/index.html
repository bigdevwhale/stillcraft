Principles

Made slowly, on purpose.

No accounts

No sign-up, no login, no email. Open it and use it.

Your data stays yours

Journal, worries, focus photos and stats live only on your device. There is no analytics.

Open source

Every app is on GitHub. Read the code, build it yourself, send a fix.

Built for the platform

Kotlin and Jetpack Compose on Android, a tray app on Windows. No web views pretending to be apps.

Two languages

Every screen, practice and prompt is in English and Russian.

Nothing to buy

No ads, no subscriptions, no paid tiers. Download the file from GitHub and that's it.

Let's make the next one together.

Tell us which moment of your day needs more quiet. It might become the next app.
