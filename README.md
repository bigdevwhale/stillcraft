# Stillcraft

Small tools for a quieter mind. Landing page for a family of calm, offline, open-source apps:

- [Anyway](https://github.com/bigdevwhale/anyway): memento mori for Android
- [SwissZen](https://github.com/bigdevwhale/SwissZen): the mindfulness multi-tool for Android
- [FocusShield](https://github.com/bigdevwhale/focus-shield): a strict focus timer for Windows
- [Ties](https://github.com/bigdevwhale/ties): a gentle nudge to keep in touch, for Android
- [Unhook](https://github.com/bigdevwhale/unhook): quit a habit, one day at a time, for Android
- [Dayquest](https://github.com/bigdevwhale/dayquest): turn your days into a quest, a pixel-art habit RPG for Android

Live: https://bigdevwhale.github.io/stillcraft/

Static site, no build step; GitHub Pages serves the `main` branch root.

- `index.html`: the landing page
- `apps/index.html`: the app catalog (`/apps/`)
- `apps/<slug>/index.html`: one page per app, generated by `tools/build_app_pages.py`
- `assets/site.css`, `assets/site.js`: shared styles, language switch (EN/RU) and the breathing orb
- `assets/`: screenshots and icons

## Adding an app

1. Put its images in `assets/`.
2. Landing: copy one `<article class="app ...">` block in `index.html` and give it its own palette class.
3. Catalog: copy one `<a class="card">` in `apps/index.html` (version, status and platform badges).
4. App page: add an entry to `APPS` in `tools/build_app_pages.py` (every text is an English/Russian pair), then run `python tools/build_app_pages.py`. Don't edit the generated pages by hand.
5. Add the Russian strings for the landing and catalog to `I18N.ru` in `assets/site.js`.
6. Update the app counts, the footer links on both pages and the closing download buttons.

After changing `assets/site.css` or `assets/site.js`, run `python tools/build_app_pages.py` too: it stamps every page with `?v=<hash>` so visitors don't get a stale cached copy.
